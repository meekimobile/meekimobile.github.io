Drag the cube to rotate it manually.

Raw WebGL

The cube is drawn with a hand-written vertex and fragment shader, a depth buffer and per-vertex colors — nothing else.

Interactive

Pointer drag rotates the scene, and the controls change the animation speed live.

Lightweight

No build step and no dependencies. Open index.html and it just runs.

How it works

  1. A <canvas> element requests a WebGL context.
  2. Shaders compile from GLSL source strings in JavaScript.
  3. Vertices are uploaded to a buffer once, then drawn each frame.
  4. A rotation matrix from time + drag input animates every frame.
